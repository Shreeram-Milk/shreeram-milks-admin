# Admin Gujarati glossary

Every word list uses these words, so one thing is always called the same. The style is everyday Gujarati, with the English words
people already use written in Gujarati script. Digits stay 0–9. Names people type (products, customers, addresses) are not
translated. A word the owner corrects is changed here first, then in the word lists.
